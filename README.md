# EduBoard – Learning Management System

A full-stack Learning Management System (LMS) built using the MERN stack that enables instructors to create, manage, and publish courses while providing students with a seamless learning experience through secure authentication, AI-powered course discovery, and online payments.

**Live Demo:** https://lms-1-tzhr.onrender.com/

---

## Overview

EduBoard is designed to simplify online learning by offering separate experiences for students and instructors. Instructors can create and manage courses, upload lectures, and organize learning content, while students can browse courses, enroll securely, and access purchased content through a modern and responsive interface.

---

## Features

- AI-Powered Smart Search using Google Gemini
- Google Authentication
- Secure Course Enrollment with Razorpay Payment Gateway
- Student and Instructor Dashboards
- Course Creation and Management
- Lecture Upload and Management
- Course Reviews and Ratings
- Redux Toolkit for State Management
- Protected Routes and Secure Authentication
- Cloudinary Integration for Media Storage
- Fully Responsive User Interface
